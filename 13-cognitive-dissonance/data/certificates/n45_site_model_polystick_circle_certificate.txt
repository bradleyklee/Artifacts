N=45 SITE-SET / POLYSTICK CIRCLE FACT SHEET
=============================================

SCOPE
  This certificate describes the 12 canonical 45-site representatives
  emitted by the original occupied-lattice-site circle enumerator
  (depth-1 hereditary run). Each listed circle is independently checked
  below against the full integer lattice.

  It certifies the 12 dumped representatives and their witnesses.
  It does not, by itself, prove that no other 45-site representatives
  exist outside that enumerator's hereditary search regime.

MODEL: LATTICE SITES, NOT FILLED UNIT SQUARES
  A stored coordinate p=(i,j) is the actual physical lattice point (i,j)
  in Z^2. A closed disk D(C,r) represents the selected site set P exactly
  when
      P = D(C,r) intersection Z^2.

  A polystick drawing places a vertex at each selected site and joins
  horizontally/vertically adjacent selected sites by unit bars.
  There is NO square-area or square-corner condition in this model.
  Earlier drawings that showed black squares used them only as point glyphs
  centered at the selected lattice sites; they are not geometric cells.

SWEEP CONVENTION
  For each listed anchor pair A,B and rational parameter t:
      C(t) = (A+B)/2 + t * (-(B_y-A_y), B_x-A_x),
      r^2  = |A-C(t)|^2 = |B-C(t)|^2.
  All displayed values are physical coordinates. There is no doubled-grid
  encoding and no global coordinate shift in this certificate.

EXACT GLOBAL CHECK
  For each S01...S12, every integer lattice point in a finite bounding box
  containing the disk was tested by exact rational squared-distance comparison.
  Result for every witness: 45/45 listed sites inside; 0 missing; 0 extra.

D4 UNIQUENESS CHECK
  Each of the 12 coordinate sets was normalized under all 8 rotations and
  reflections of the square lattice. Number of distinct free-polyomino
  canonical forms: 12. No two listed shapes are congruent by a D4 motion.
