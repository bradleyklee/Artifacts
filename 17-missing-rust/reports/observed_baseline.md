# Observed Baseline

The current capability report is generated by `python3 run_probe.py`; the
most recently generated, exportable snapshot is `reports/latest_probe.md`.

All language samples use the same exact workload: decimal expansion by integer
long division of the rational pi approximant `355 / 113`. The test emits only
four fractional digits, so `355 / 113 = 3.141592920...` yields the required
`hello 3.1415 world!` without floating point or a math library.

## Historical Rust boundary

| Rust path | Observed status |
| --- | --- |
| Fresh PATH in the investigated sandbox | `rustc`, `cargo`, and `rustup` absent |
| Uploaded Rust 1.96.0 GNU x86_64 | `cargo` launched; `rustc --version` SIGBUS / shell exit 135 |
| Different context's managed offline toolchain | reported successful 100,000-event Go/Rust parity control |

The uploaded-toolchain result is a historical, scoped incident—not a universal
claim about all Rust versions or execution surfaces. The transferred successful
control is documented in `../evidence/RUST_LOCAL_SUCCESS.md`; it is integrity-
checked here but not replayed because the originating context's mount is not
visible. `rust/FAILED_HELLO_WORLD.md` records the Rust result of the most recent
local capability probe.
