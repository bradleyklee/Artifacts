# Dataset status

`three-body` contains 13 source-recommended L=4 seeds.  Three pairs were later
identified as phase-shifted D4/relabelled copies at the stored finite prefix;
the data are retained because the certificate records are useful, but they are
not independent samples for statistical comparison.

`clock` contains five survivor masks: 086 (four bodies), 031/091/124 (five),
and 125 (six).  They were selected by a strict exact search and each stored
prefix ends at the common 192-bit coefficient complexity cutoff.  Clock pair
tables retain a pair contact in a valid disjoint pair-plus-wall batch.  No
clock ternary encoding is stored.
