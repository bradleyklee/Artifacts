# 06. sage-hexings

This artifact records a first reduced two-hex Spectre-style model and a small
local forcing experiment.  The point is not to claim a final proof, but to make
the reduced edge/vertex rules executable and printable so the resulting local
closures can be inspected and corrected.

## New action

The command `make all` regenerates the PDF/SVG artifacts, verifies the reduced
model, reruns the exact 9-hex-to-2-hex reduction search, and runs a weak local
forcing scan over every legal adjacent oriented two-hex seed.  The scripts use
only Python's standard library; there is no `matplotlib`, Sage, or ReportLab
dependency.

```bash
make all
make verify
make reduce   # verbose reduction search with status prints
make scan
```

`make verify` is now intentionally more than a count check.  It first checks the
local two-hex model, then calls `src/reduce_exact.py` on the source 9-hex model.
The reducer prints accepted merges, best-so-far tile counts, rejection counts,
and the recovered two-tile path.  `make reduce` runs the same reducer with
`--verbose` so pair trials and per-state progress are visible.

## Data

`data/spectre_unified_model_v0.dat` is the source neutral model used for the
reduction search.  It contains:

- 9 source hex tiles;
- 33 directed edge rules;
- 18 cyclic vertex triples;
- 23 remembered free-Wang rows.

`data/reduced_spectre_model.dat` is the current two-hex presentation used for
pictures and forcing experiments:

- `H1: H A D E B G`
- `H0: C A B F G I`
- the same 33 directed edge rules after relabeling;
- the same 18 cyclic vertex triples after relabeling.

The edge rules are directed.  The singular H1 rules highlighted in the figures
are:

```text
H,A = C,A
A,D = C,A
G,H = A,B
```

## Derivation snapshot

The two-hex model is obtained by an exact vertex-merge search on the source
9-hex model.  A merge is accepted only if all of the following hold:

1. the 23 remembered free-Wang rows remain injective after relabeling;
2. the transported slot matrix is unchanged, with cyclic row offsets respected;
3. rebuilding free-Wang rows from the reduced source tiles, reduced edge rules,
   and reduced vertex triples gives exactly the mapped 23 rows;
4. no rebuilt extra rows are allowed in this Spectre exact-mode reduction.

A representative recovered path is:

```text
X=b13 b1=b2 b10=b11 b5=b6 b8=b9
```

which is the same partition as the earlier hand notation
`b2=b1 b5=b6 b13=X b9=b8 b11=b10`.

The local forcing code then works on the two-hex presentation.  The weak scan
fills any boundary site with exactly one candidate.  The strong configuration
figure additionally records the local branch kill where the H1 alternative dies
and the H0 alternative is forced.

## Generated files

`make all` writes:

```text
out/spectre_hex_fact_sheet.pdf
out/strong_forced_configuration.pdf
out/strong_forced_configuration.svg
out/strong_forced_configuration_report.txt
out/weak_scan_summary.txt
out/exact_reduction_summary.txt
out/exact_reduction_verbose.txt   # written by make reduce
```

The fact sheet contains the two reduced hex tiles, the edge rules, the vertex
rules, and a compact check summary.  The strong-forcing PDF is a separate large
diagram of the current seven-tile forced configuration with boundary branch
counts.

## Generated data flow

The source of truth is `data/spectre_unified_model_v0.dat`, the 9-tile neutral model with free-Wang rows.  The reduced two-hex file `data/reduced_spectre_model.dat` is generated by `src/reduce_exact.py`; do not edit it by hand.  `make verify` reruns the exact reducer, rewrites `data/reduced_spectre_model.dat`, then verifies the local forcing model.  `make artifacts` and `make scan` both read the generated reduced file, so the PDFs, SVGs, reports, and weak-scan summaries all depend on the reproducible 9 -> 2 reduction rather than on a manually maintained reduced model.

### Two-model equivalence verification

`make verify` now treats `data/spectre_unified_model_v0.dat` as the source of truth and regenerates `data/reduced_spectre_model.dat`.  The reducer then checks the generated two-hex model against the raw nine-hex model: mapped tiles, directed edge rules, vertex triples, remembered free-Wang rows, exact rebuild of the reduced rows from the reduced rules, and the transported slot matrix must all agree.  This does not assert that every original 9-tile label can be recovered from a single central tile in isolation; it asserts that the remembered one-ring/free-Wang row language and adjacency matrix used here are exactly preserved by the quotient.


## Real-time status printing

`make reduce` streams every accepted merge and frequent pair-trial status lines while it searches the exact 9→2 quotient. `make scan` streams weak-closure scan checkpoints while it enumerates adjacent oriented two-tile seeds; use `make scan-verbose` to print every legal seed as it is tested.
