# Adversarial review packet

This folder is a compact handoff for an outside reviewer. It does not ask the
reviewer to trust the Go engine or any visual.

Start with `REVIEW_PROMPT.md`, then independently reconstruct one full
certificate and one negative atlas. The critical distinction to preserve is
finite survival versus a proof of chaos: every `CAP` statement is a finite
prefix statement only.

Inputs reside in the parent artifact and are referenced by relative path so the
reviewer can choose whether to inspect raw JSON or rewrite from the experiment
contract.
