# Change log: release v2

- Flattened the examples tree to `examples/`; removed the unused category split.
- Added a machine-readable research ledger and a human search ledger.
- Added OEIS status for every stored period sequence.
- Implemented and verified the one-tacnode quartic family.
- Added T0, whose period and Laurent certificate transfer from baseline model 1.
- Added T1, with 51 exact period coefficients and a checked order-three equation.
- Exhausted the degree-5 and degree-6 palindromic product search for models 4,
  8, and 10.
- Recorded the 495-support rank-two bounded exclusion for the same models.
- Rewrote the legacy certificate verifier with explicit sparse exact arithmetic,
  reducing the full audit to about 30 seconds on the release machine.
- Updated the release note, search plans, model table, and PDF summary.
