# Pseudocode library

This folder holds the current language-neutral algorithm layer used to guide
and compare implementations.

- `ALGORITHM_SPACE_SEARCH_SPEC.md` defines the outer algorithm-search program.
- `PLANE_CURVE_ODE_PSEUDOCODE_V0_2.md` gives the current universal front end
  and scalar-chart/action-fiber backends.
- `pseudocode_index.json` records candidate identity and evidence status.
- `pseudocode_feature_matrix.json` compares currently recorded features.
- `algorithms/` contains recovered complete candidate pseudocode.
- `notes/` contains current application-specific search notes.

The two historical bodies explicitly marked unrecovered in the index are not
silently replaced by new prose; see the root state-preservation audit.
