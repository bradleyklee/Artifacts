# Pseudocode

This is executable research memory. Each document should state inputs, outputs, normalization, finite bounds, exact operations, failure returns, and successful examples.

- `plane/` contains plane-curve search and reduction pseudocode.
- `sphere/` contains the current sphere, quotient, action-angle, and perturbation procedures.
- `comparisons/` contains the independent Lairez-style comparison procedures.
- `algorithm_registry.json` and `algorithm_feature_matrix.json` retain the current implementation/status map.

When code changes in a way that affects what a filed example can reproduce, update the corresponding pseudocode and case record in the same revision.
