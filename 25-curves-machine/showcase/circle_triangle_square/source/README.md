# Circle Triangle Square Periods - showcase project

This is the complete, cleaned source project for the one-page showcase
certificate and its autonomous-referee payload.

## Fast rebuild

The canonical embedded figure PDF is already included, so the normal build does not
need to recompute the numerical contours and periods.

```bash
python3 -m pip install -r requirements.txt
python3 build.py
```

The final PDF is written to:

```text
release/circle_triangle_square_periods_certificate_v19_payload.pdf
```

The build performs these steps:

1. copies the current LaTeX source into the payload;
2. runs the exact/numerical certificate verifier;
3. updates `payload/MANIFEST.sha256`;
4. compiles the one-page PDF with `pdflatex`;
5. embeds the standardized source and referee bundle into the PDF.

## Regenerate the figure from code

```bash
python3 build.py --regenerate-figure
```

This recomputes the connected quantized ovals and numerical period curves before
compiling the PDF. It is slower and requires NumPy, SciPy, Matplotlib,
ContourPy, and Pillow.

## System dependency

A TeX installation containing `pdflatex` and the packages used in
`certificate_source.tex` is required. On TeX Live these include `extsizes`,
`charter`, `euler`, `amsmath`, `microtype`, `graphicx`, `array`, `tabularx`, and
`ragged2e`.

## Project layout

```text
certificate_source.tex       one-page certificate source
assets/                      canonical embedded figure PDF
payload/                     autonomous-referee data and verifier
scripts/generate_figure.py   code-only figure reconstruction
scripts/update_manifest.py   payload checksum generator
scripts/attach_payload.py    PDF attachment step
build.py                     end-to-end build
release/                     finished payload PDF
```

No prior versions, LaTeX logs, `.aux` files, or duplicate unpacked releases are
included.

## Standardized source bundle

This source-standardized edition leaves the visible certificate unchanged and
adds the figure generator, midpoint action-level generator, quantization
specification, checked level table, LaTeX source, verifier, and hashes to the
PDF attachments.


Machine-readable proof coverage
------------------------------
`claim_index.json` maps visible certificate rows to named checks.
`verification_results.json` is regenerated by `verify_certificate.py` and records 13 passed proof-level checks.
