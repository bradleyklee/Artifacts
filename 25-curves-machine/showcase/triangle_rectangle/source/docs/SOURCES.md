# External source used by the certificate

S. Ramanujan, *Modular equations and approximations to pi*, Quarterly Journal
of Mathematics **45** (1914), 350-372.

Source supplied during the session:

https://ramanujan.sirinudi.org/Volumes/published/ram06.pdf

The visible certificate cites Section 9 for the identity

`E4(tau) = (2 K(k) / pi)^4 (1 - k^2 k'^2)`

using Ramanujan's nome convention. The exact symbolic pullback and geometric
normalization used in this project are independently checked by the included
scripts.
