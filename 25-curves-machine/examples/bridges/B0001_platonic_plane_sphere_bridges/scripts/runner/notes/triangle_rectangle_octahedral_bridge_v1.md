# Triangle–rectangle ↔ octahedral sphere bridge, stage 1

## Result

The triangle–rectangle Hamiltonian is not merely another genus-one family
with an unrelated hypergeometric expression. It carries the same natural
degree-two isogeny architecture as the octahedral sphere quotient.

This is currently the strongest exact bridge between the new plane model and
the sphere story.

## 1. The plane Hamiltonian period descends exactly

The certificate gives

    12*y^2 = -x^4 + (2+12*alpha)*x^2 + 4*alpha - 1,

    omega_TR = dx/(sqrt(3)*y).

Set

    U = -x^2,
    W = 2*sqrt(3)*x*y.

Then

    W^2 =
      U^3 + (2+12*alpha)*U^2 + (1-4*alpha)*U,

and, exactly,

    omega_TR = -dU/W.

Thus the actual Hamiltonian period form descends to the canonical differential
on a cubic with rational 2-torsion. This is a genuine quotient of the
Hamiltonian curve, not only a matching Picard–Fuchs operator.

## 2. The sphere Hamiltonian period also descends exactly

For the octahedral invariant

    Q = x^2*y^2 + y^2*z^2 + z^2*x^2

on

    P = x^2+y^2+z^2 = 1,

put

    R = x^2*y^2*z^2,

    S = x*y*z*(x^2-y^2)*(y^2-z^2)*(z^2-x^2).

The Goursat identity is

    S^2 =
      -27*R^3 + (18*Q-4)*R^2 + Q^2*(1-4*Q)*R.

For the Lie–Poisson flow generated by H=Q,

    dR/dt = -4*S,

so

    dt = -dR/(4*S).

Therefore the physical sphere time differential also descends to the
canonical differential on the rotation quotient, up to a fixed constant.

This puts the two Hamiltonian problems on genuinely comparable quotient
curves.

## 3. Both sides are pullbacks from X_0(2)

For a cubic

    y^2 = x^3 + A*x^2 + B*x,

define the level-two Hauptmodul

    h = 256*B/(A^2-4*B).

The associated degree-two isogeny pair has

    j0(h) = (h+256)^3/h^2,

    j1(h) = (h+16)^3/h.

For triangle–rectangle,

    h_TR(alpha) =
      16*(1-4*alpha)/(alpha*(9*alpha+4)).

Its quotient cubic has j=j0(h_TR), while the original quartic has
j=j1(h_TR).

For the octahedral sphere quotient,

    h_O(q) =
      -432*q^2*(4*q-1)/(3*q-1)^3.

The sphere quotient 234III has j=j0(h_O), while its 2-isogenous companion
126III has j=j1(h_O).

Hence the algebraic relation

    h_TR(alpha) = h_O(q)

simultaneously aligns the full isogeny square:

    triangle-rectangle quotient  <->  234III sphere quotient,

    triangle-rectangle original  <->  126III plane companion.

This is stronger than a single equality of j-invariants.

## 4. Exact energy correspondence

The orientation-preserving energy curve is

    972*alpha^2*q^3
      -243*alpha^2*q^2
      +324*alpha*q^3
      -36*alpha*q
      +4*alpha
      +27*q^3
      -27*q^2
      +9*q
      -1 = 0.

Its normalization is genus one. Near the octahedral triangular well, put

    q=(1-u)/3.

The two branches are

    alpha =
      u^3/4 + 3*u^4/2 + 27*u^5/4 + 1767*u^6/64 + ...

and

    alpha =
      -4/9 - 25*u^3/36 - 25*u^4/6
      -75*u^5/4 - 44575*u^6/576 + ...

Thus both singular triangle–rectangle fibres lying over the same X_0(2)
cusp connect cubically to the octahedral triangular sphere well.

There is also an Atkin–Lehner-swapped correspondence

    h_TR(alpha)*h_O(q)=4096,

which interchanges the two members of each 2-isogeny pair.

## 5. Interpretation

We have not yet proved a global canonical transformation between the plane
Hamiltonian and the sphere Hamiltonian. The energy relation is algebraic and
ramified.

But the relationship is now substantially stronger than “the periods happen
to be hypergeometric”:

1. both physical period forms descend exactly to canonical elliptic
   differentials;
2. both descended families have rational 2-torsion;
3. both are pullbacks of the same universal X_0(2) isogeny family;
4. there is an explicit genus-one energy correspondence aligning the sphere
   quotient and its isogenous plane companion with the two natural
   triangle–rectangle curves.
