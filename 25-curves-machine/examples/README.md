# Examples

Examples are organized by mathematical domain, not by publication status. Most of this repository is private research for now.

A case identifies a mathematical object or a declared family/study. Coordinate systems belong inside the case under `representations/`. Runs and certificates must identify the representation they use. Separate cases are used only when mathematical equivalence has not been established or the parameters define genuinely different objects.

The stable ID is authoritative. Directory slugs and display names may improve over time.
